# Area Annotator for Google Maps

A Chrome extension for drawing numbered, colored polygon areas on Google Maps and exporting their coordinates as GeoJSON, WKT or Lat/Lng JSON.

- Website: https://johnelro.github.io/area-annotator/
- Privacy policy: https://johnelro.github.io/area-annotator/privacy.html
- Support: [open an issue](https://github.com/johnelro/area-annotator/issues)

This repository holds the extension's website, privacy policy and issue tracker. The extension's source code is not published here.
